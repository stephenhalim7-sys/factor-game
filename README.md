# Factor Game — AI-based Interactive Game

## Project Overview
This project is an interactive game developed for the **Artificial Intelligence** course at Airlangga University. **Factor Game** is a turn-based mathematical strategy game played against an AI agent or another player. The goal of the project is to implement AI algorithms that optimize decision-making strategies in selecting factors to maximize the total score.
